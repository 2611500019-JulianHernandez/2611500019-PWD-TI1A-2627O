Bukti Belajar P1
Fungsi: dokumentasi capaian pembelajaran P1

1. Konsep Dasar Pemrograman Web
   Pemrograman web proses bikin website yang didalamnya ada bagian untuk ngatur tampilan,fungsi,data,dan komunikasi antara pengguna dengan server.
2. Arsitektur Klien-Peladen
   Client : Perangkat yang dipake pengguna.
   Server : Komputer yang nerima permintaan dari client terus ngolahnye.
   Alurnya : Client - Request - Server - Response - Client
3. HTTP Request dan Response
   Request : Permintaan dari client ke server.
   Response : Jawaban dari server ke client.
   GET : biasanye buat ngambek data.
   Post : buat ngirim data.
   200 : Berhasil.
   404 : Halaman atau data dak ditemukan.
   500 : ade kesalahan diserver.
4. HTML, CSS, JavaScript, PHP, MySQL
   HTML : Buat struktur halaman.
   CSS : Ngatur tampilan halaman.
   JavaScript : Bikin halaman jadi interaktif.
   PHP : Ngolah data dan proses diserver.
   MySQL : tempat nyimpen dan mengatur data.
5. Hubungan Antarteknologi
   Kelime teknologi ni saling berhubungan:
   HTML : Struktur
   CSS : Tampilan
   JavaScript : Interaksi
   PHP : Proses data
   MySQL : Nyimpen data
