# Pertemuan 3 - Formulir HTML dan CSS Dasar

## Baseline
- Menggunakan hasil P2 sebagai dasar pengembangan P3.
- Menyalin `index.html` dan `img/foto-profil.jpg` ke `pertemuan-03/`.

## Implementasi Formulir
- Elemen form yang digunakan: [form,label,input,textarea,select,option,button]
- Tipe input yang digunakan: [text,email,password,number,date,radio]
- Atribut validasi yang digunakan: [required,minlength,maxlength,min,max,pattern]

## Pengujian GET dan POST
- Hasil pengujian GET: [Data yang diisi diformulir berhasil dikirim dan dapat dilihat di URL]
- Contoh URL encoding yang ditemukan: [spapsi berubah menjadi %20]
- Hasil pengujian POST: [Data formulir berhasil dikirim dan dak ditampilkan URL]

## CSS Dasar
- Selector elemen: [body,h1,p,form]
- Selector class: [container,judul]
- Selector ID: [formulir,nama]
- Properti CSS dasar yang digunakan: [color,background-color,font-size,font-family,margin,padding,border,width,text-align]

## Pengujian dan Perbaikan
- Galat yang ditemukan: [Ade beberapa bagian formulir yang dak tampil atau dak berfungsi dengan benar]
- Penyebab galat: [Ade kesalahan dalam penulisan kode HTML dan CSS]
- Perbaikan yang dilakukan: [Ngecek dan memperbaiki kembali kode HTML, CSS, dan atribut formulir]
- Hasil pengujian ulang: [Setelah diperbaiki, formulir sudah dapat digunakan dengan baik dan tampilannyo sudah sesuai.]
